# Eco Clinic

Редизайн сайта клиники косметологии [ecoclinic.pro](https://ecoclinic.pro/) — та же информация и разделы, новая бьюти-подача.

## Стек

- Next.js 15 (App Router)
- Tailwind CSS 4
- TypeScript

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Страницы

- `/` — главная
- `/uslugi` и `/uslugi/[slug]` — каталог и карточки услуг
- `/vrachi` — специалисты
- `/o-klinike` — о клинике, философия, реквизиты
- `/stati` и `/stati/[slug]` — полезная информация
- `/prajs` — прайс и акции
- `/licenzii` — лицензии
- `/politika` — политика конфиденциальности
- `/kontakty` — адрес, телефоны, карта, форма записи

Онлайн-запись ведёт на виджет Dikidi клиники. Контент и контакты взяты с действующего сайта Eco Clinic.
